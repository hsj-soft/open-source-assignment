# 📱 My Bank
오픈뱅킹 API를 활용한 개인 맞춤형 통합 계좌 관리 모바일 앱
## ✨ 주요 기능
- **전 계좌 통합 조회**: 모든 은행 계좌의 잔액과 거래 내역을 실시간으로 확인합니다.
- **자동 가계부**: 입출금 내역을 카테고리별로 자동 분류합니다.
